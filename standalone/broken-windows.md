# Broken Windows and the One Unfixed Thing
**Tier:** 100 — Recognize | **Arc:** Standalone

**Goal:** After this piece, you will be able to recognize when a small, unfixed thing is sending a "neglect is acceptable" signal — and use a deliberate small fix to reset it.

**Trigger:** something small and visibly neglected has been sitting untouched for a while.

**Method:** fix the smallest visible thing first, not the biggest. Small, visible neglect signals that neglect is acceptable — fixing it resets that signal.

**Artifact:** one small fix, done on purpose, as a signal.

**Proof:** The signal a small, unfixed thing sends — that neglect is acceptable — is already being sent whether or not anyone decided to send it. Fixing it resets that signal deliberately. The fix itself is small; the reset it performs is not.

**Don't confuse this with prioritization** — fixing the smallest visible thing is a signal tool, not a prioritization method. The broken window you fix first is not necessarily the most important thing to fix. It's the one that resets the "neglect is acceptable" message. Real debt prioritization still requires impact/effort analysis.

**Try This:** name the smallest unfixed, visible thing in something you're currently working on. Fix it today — not because it's important, but because fixing it resets what the product signals about standards.

**What Next:** if fixing the small thing reveals a larger pattern of accumulated neglect, read 300 (The Cost You Don't See) for the habit of flagging design debt before it compounds. If the broken window is a labeling or copy problem, read 205 (Content Design) for how to fix it in a way that holds.
