# Tier 300 — Judgment Arcs

**36 arcs.** Each is a multi-part system for navigating a complex situation — the kind where multiple methods interact, where seams between phases matter, and where judgment determines whether the method produces the right result.

Every arc is self-contained: parts can be read individually, but the arc as a whole follows a progression from recognition through judgment. Each arc closes with a **Judgment Exercise** — a specific failure case where the arc's key assumption doesn't hold, requiring you to decide what changes and what gets cut.
