# Generative vs. Convergent Thinking
**Tier:** 100 — Recognize | **Note:** Foundational prereq for 304 (Running One Workshop) and 203 (Structured Ideation); pairs with 163 (Alignment vs. Consensus)

**Goal:** Recognize when a session is in generative mode versus convergent mode — and name the shift when it needs to happen.

**Concept:** Generative thinking expands what's possible — it produces options, reframes, and new angles. Convergent thinking narrows — it evaluates and selects among what exists. They operate against each other: convergent questions kill generative momentum, and generative questions reopen convergent decisions. Effective sessions sequence both modes deliberately, with an explicit transition between them.

**You'll see it when:** A brainstorm starts evaluating ideas before it's finished generating them. Or a decision session generates new options instead of evaluating the ones already on the table. The mode being used doesn't match the mode the session needs.

**The signal:** People in the wrong mode for the moment — evaluating when they should be generating, or generating when a decision needs to be made. The clearest signal is an evaluative response to a generative prompt ("yes, but that won't work because...") or a generative response to a convergent one ("what if we also considered...").

**Don't confuse this with:** Creativity vs. analysis — this isn't about how imaginative the thinking is. Analytical thinking can be generative ("what are all the ways this assumption could be wrong?") and creative thinking can be convergent ("which of these ideas best fits the constraint?"). The distinction is about the cognitive operation, not the content or quality.

**Try Noticing:** In the next meeting you're in, notice when someone switches mode without naming the switch. Does the room follow, or does it pull back to the previous mode? The friction at that moment is the mode mismatch.

**What Next:** If you're designing a session that needs both modes in sequence, read 304 (Running One Workshop) for the facilitation mechanics that signal the transition. If the session's primary goal is generative, read 203 (Structured Ideation).
