# Framing Effect
**Tier:** 100 — Recognize | **Arc:** Standalone | **Prereqs:** 247, 131 | **Cluster:** J — Cognitive Science

**Goal:** Recognize when the framing of a message is doing more work than its content — so you can notice when identical information is likely to land differently based on how it's presented.

**Concept:** The working assumption is that neutral presentation of options produces neutral decisions — that if the information is accurate, how it's packaged doesn't change the outcome. The correction: System 1 anchors on the first frame it encounters and uses that anchor as the reference point for all subsequent evaluation. The same facts, presented as a gain ("we'll recover 20% of users we're currently losing") or as a loss ("we're losing 20% of users we could be retaining"), activate different S1 responses before S2 engages. The content is identical. The emotional weight is not.

The mechanism: S1 doesn't evaluate information in isolation — it evaluates it relative to a reference point. Frames establish the reference point. Once set, adjustment from that anchor is systematically insufficient: the first frame has outsized influence on the final conclusion even after S2 attempts to re-evaluate. This applies to every proposal, recommendation, and change communication where what's introduced first shapes how everything that follows is interpreted.

**The move:** Take one message you're currently working on — a proposal, a recommendation, a communication about a change. Write two versions: one that leads with what's being lost or changed, one that leads with what's preserved and what becomes possible. Read both back as if you'd received them cold. Which one produces the urge to push back immediately, and which one produces the urge to ask questions? The difference between those two responses is the framing effect working on you directly.

**Don't confuse this with:** Spin or strategic misrepresentation. Framing is a choice between accurate descriptions — the question is which true description to lead with, not which untrue description is most persuasive. The false positive: writing a version that leads with gains and feeling like you've manipulated the situation. You haven't, unless you omitted something real. An accurate message that's more likely to be genuinely received is appropriate communication, not manipulation.

**Try Noticing:** In the next proposal or recommendation you read, notice what the first sentence establishes as the reference point. Is this framed as adding something or fixing something? Improving on a baseline or reversing a loss? The reference point set by the opening is doing more work than the content that follows it.
