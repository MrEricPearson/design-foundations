# Layout Principles: Proximity, Alignment, Repetition, Contrast
**Tier:** 100 — Recognize | **Arc:** Standalone | **Prereqs:** None | **Note:** Visual craft foundation; prereq for 188, 189; read before any visual critique or layout work

**Goal:** After this piece, you will be able to recognize when a layout is communicating relationships accidentally rather than intentionally — and identify which principle is violated.

**Concept:** Layout is not aesthetic arrangement. Layout is a communication system. Before a user reads a word on a page, four signals have already told them what belongs together, what's most important, what's the same kind of thing, and what's different. Those signals are proximity, alignment, repetition, and contrast — and they operate before conscious attention, at the level of perceptual grouping.

**Proximity** communicates belonging. Elements close together are perceived as a group, regardless of any other visual property. A label placed close to the wrong field belongs to that field — the user's brain assigns it there automatically. A section heading with too much space above it and too little below it looks like it belongs to what precedes it rather than what follows. The space ratio determines what the heading leads.

**Alignment** communicates relationship. Elements that share an edge — left, right, center, baseline — are understood as related. Elements that don't share an edge introduce visual "drift" — the brain registers the misalignment and works to assign meaning to it. Misalignment where none was intended adds unexplained noise.

**Repetition** communicates system. The same visual treatment used consistently across elements tells the user: "these are the same kind of thing." When primary action buttons look the same everywhere, users know, without reading, that this element is an action. When headers follow a consistent hierarchy, users know what level of content they're in. Repetition is how a local pattern becomes a system-level language.

**Contrast** communicates priority. The element most visually different from everything around it attracts attention first. A single bold word in a block of regular text. A dark button on a light background. A large number surrounded by small labels. Contrast tells the user: this matters more. When too many things contrast with their surroundings, nothing stands out — the contrast hierarchy collapses.

The mechanism underlying all four: the brain groups elements before reading them, using these four signals. Designers who understand this are communicating intentionally at the perceptual level. Designers who don't are communicating accidentally — and the accidental messages frequently contradict the intentional ones.

**You'll see it when:** A design "looks fine but feels confusing." The information is present, but the groupings feel wrong, or the priority seems inconsistent, or the system feels fragmented rather than cohesive. These feelings are almost always traceable to a violation of one of the four principles — something is grouped that shouldn't be, something isn't visually related that should be, the treatment isn't consistent for the same type of element, or too many things are competing for first attention.

**The signal:** A user has to read multiple elements to figure out which one they should act on first, or which elements belong to which section. That's the signal that contrast or proximity is miscommunicating.

**Don't confuse intentional contrast with decoration** — adding visual variety (different colors, different sizes, different weights) for aesthetic interest is not the same as using contrast to signal priority. Decorative variety without semantic intent creates noise, not hierarchy. Every contrast decision should answer the question: what does this visual difference signal to the user about relative importance?

**Try Noticing:** Pick one screen in a product you use. Apply each principle as a lens — one at a time. For proximity: which elements are close together? Do they belong together? For alignment: pick any two elements — do they share an edge or baseline? Is the misalignment intentional? For repetition: do all elements of the same type look the same? Where does the treatment break and why? For contrast: which element catches your eye first? Is that the most important element? Work through all four before deciding whether the layout is communicating correctly.
