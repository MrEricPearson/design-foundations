# Interface Copy vs. Marketing Copy
**Tier:** 100 — Recognize | **Note:** Soft prereq for 205 (Content Design / UX Writing); pairs with 205

**Goal:** Recognize when copy is doing interface work versus marketing work — so you can apply the right standard to each.

**Concept:** Marketing copy sells a product: it creates desire, builds brand, and is meant to be persuasive. Interface copy operates a product: it tells users what to do, what just happened, and what will happen next. Marketing copy can be evocative, aspirational, and personality-forward. Interface copy has to be precise, immediate, and action-enabling — if a user reads it and still doesn't know what to do, the copy has failed regardless of how clever it sounds.

**You'll see it when:** A button label or error message is written in a brand voice that's engaging but imprecise — "Let's do this!" instead of "Submit application" or "Save and continue." The marketing tone is appropriate in many contexts; in a moment where the user needs to know exactly what action they're taking, it introduces ambiguity that precedes copy written for clarity.

**The signal:** The copy appears at a moment where the user must take an action or understand the current state. At those moments, the standard shifts from "does this sound like us?" to "does this tell the user what they need to know to proceed without uncertainty?" Copy that passes the brand test but fails the precision test is marketing copy in an interface context.

**Don't confuse this with:** All brand personality being wrong in interfaces — some personality in interfaces is desirable and appropriate. The distinction is about the priority at the specific moment: in a decision point or error state, precision wins over personality. In a confirmation screen or onboarding welcome, personality can appropriately take more room.

**Try Noticing:** Find one button label, error message, or status notification in a product you're working on. Ask: does this tell me exactly what will happen or what has happened? Or does it tell me how the product feels about itself? If the second — that's marketing copy in an interface context.
