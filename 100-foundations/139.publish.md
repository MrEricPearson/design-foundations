## Source attribution block (P8)

**Label:** Sources

Norman, D.A. (1998). *The Invisible Computer: Why Good Products Can Fail, the Personal Computer Is So Complex, and Information Appliances Are the Solution*. MIT Press. — Foundational argument that good technology design makes the interface invisible; "people's needs first, technology second."

Krishna, G. (2015). *The Best Interface Is No Interface: The Simple Path to Brilliant Technology*. New Riders. — Three principles for zero-UI design; argues screens are defaults that should be questioned rather than assumed.

Nielsen, J. (2023, June 22). AI is the first new UI paradigm in 60 years. *Jakob Nielsen's Substack*. https://jakobnielsenphd.substack.com/p/ai-is-first-new-ui-paradigm-in-60 — Names intent-based outcome specification as a new interface paradigm where users describe desired results rather than commanding steps; "the user tells the computer the desired result but does not specify how this outcome should be accomplished."
