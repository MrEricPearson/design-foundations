# Visual Hierarchy
**Tier:** 100 — Recognize (Practice Atom) | **Arc:** Standalone | **Prereqs:** none | **Episode:** 7

**Goal:** Recognize when a screen has no clear visual priority — so you can identify where the eye goes versus where it should go.

**Concept:** The working assumption is that visual hierarchy is about making things look good — that a clean, professionally designed screen has working hierarchy. The correction: visual hierarchy is a reading order question, not an aesthetic one. The mechanism: every element on a screen competes for visual attention, and the eye follows a predictable path based on weight signals — size, contrast against background, and surrounding whitespace. An element with more size, higher contrast, or more surrounding space reads as more important. When these signals aren't calibrated intentionally, the eye goes to whatever happens to be biggest or highest-contrast, which is often a secondary element (a status badge, a timestamp, a category label that got the same treatment as the primary content).

The failure mode isn't too much visual noise — it's too many elements at the same weight. When everything has equal visual priority, the eye doesn't know where to start. Scanning becomes reading.

**The move (squint test):** Blur your eyes until the screen goes out of focus — you can't read the copy but you can still see which areas are darkest/largest/most prominent. Whatever you notice first is the highest-weight element. Is it the thing a new user most needs to see first?

**Don't confuse visual hierarchy with visual design.** A beautifully styled screen can have broken hierarchy; a wireframe can have excellent hierarchy. A false positive: a screen with a prominent heading at the top feels like it has clear hierarchy. But if the primary user action sits below the fold at the same visual weight as secondary information, the heading created a visual anchor without creating a reading path through the page.

**Try Noticing:** Take one screen you're working on. Apply the squint test. Write the actual reading order (what the eye hits first, second, third). Now write the intended reading order for a new user. Where they differ, that's the hierarchy gap.
