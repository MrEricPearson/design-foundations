# Affordance
**Tier:** 100 — Recognize | **Note:** Foundational prereq for 302 (Spotting AI Surprises) and 308 (Designing for AI Trust); applies broadly across interface evaluation

**Goal:** Recognize what affordance means in interface design — so you can identify when an element communicates how it's meant to be used versus when it leaves users guessing.

**Concept:** An affordance is the relationship between an object and a person — the features of the object that suggest how to interact with it. A button that looks pressable affords pressing. A text field that looks editable affords typing. When an affordance is present and accurate, the user doesn't need to figure out how to interact — the interface communicates it. When the affordance is absent or misleading, the user has to guess, explore, or stop.

**You'll see it when:** A user hesitates at an interface element — unsure whether it's clickable, whether it's editable, whether it does something or is purely decorative. The hesitation is the affordance gap. You'll also see it in the reverse: users clicking or touching elements that aren't interactive, expecting a response that doesn't come.

**The signal:** Interaction is uncertain or exploratory at a specific element. Hovering without clicking, looking at the cursor for feedback, trying an interaction that doesn't work — or not trying an interaction that would have worked. Both directions (false positive and false negative affordance) are signs that the element isn't communicating what it does.

**Don't confuse this with:** Learnability — which is whether users can figure out how to use something over time with practice. Affordance is immediate: it's whether the interaction is self-evident in the moment, without prior experience with this interface. A product can be learnable with poor affordances (users eventually figure it out), but poor affordances add friction to every first encounter.

**Try Noticing:** Look at one interactive element in something you're working on. Could a user who has never seen this interface tell — just by looking at it — whether clicking or tapping it does something? Could they predict what it does? That immediate recognizability (or its absence) is the affordance.

**What Next:** When evaluating an interface for affordance problems across multiple elements, the Heuristic Evaluation method (216) includes recognition and feedback as evaluation criteria. For AI features where the AI takes actions on behalf of users, the affordance of AI-initiated interactions is addressed in 308 (Designing for AI Trust).
