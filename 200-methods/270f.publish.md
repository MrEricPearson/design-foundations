## Pull quote selection

> "A high-fidelity prototype signals 'this is what it will be.' Participants respond by evaluating whether the execution is right, not whether the direction is right."

**Placement:** Immediately after Concept Panel (P3), before Method (P4).
**Style:** P11 — Georgia italic 18px, max 52ch, bold top border (2px, text-1), hairline bottom border (1px, border), 24px Spacer after.
**Purpose:** F-pattern scanners reach this before the method. It names the mechanism clearly enough to stand alone as a second headline.

## Check-In question

**Pattern:** P12 — Microsoft Forms or Quick Poll web part
**Placement:** After Proof block (P7), before Take This Further
**Question:** Did you identify a design question that requires visual execution to evaluate?

| Response option | What it triggers |
|---|---|
| Yes — I found a question and scoped a prototype | If shared in [channel], link to Take This Further spaced practice |
| Not yet — still finding the question | Routing note: return to 270b to confirm structural questions are settled |
| Doesn't apply to my current work | No routing action |
