## Notes for publication coordinator

### Timing considerations
This piece should publish **after** atoms 123, 157, 159, 174 are available (all already drafted per outline). It should publish **with or before** companion piece 215b so What Next routing doesn't point to missing content.

### Audience calibration
This piece assumes:
- Reader has access to **5 participants** — if org requires design-mediated recruiting, add a note in Trigger section acknowledging this constraint
- Reader has **recording capability** — OBS Studio, Loom, QuickTime mentioned as common options; no platform-specific tool mandated
- No **IRB or formal consent process** — if publishing in regulated context, add consent/recording permission step to Method

### Legal/consent note
If organization operates under GDPR, HIPAA, or requires IRB approval for user research, add a step in Method between "Recruit 5 participants" and "Schedule 45-60 minutes" stating: "Obtain informed consent for recording and data use per your organization's research protocols."

### Design team involvement
The piece is written for practitioner self-service (consistent with project goals). If org culture requires design team involvement in usability testing, this framing may need adjustment. Current framing: "you recruit, you run, you analyze." Alternative framing would require adding "or work with a researcher to..." at recruiting and analysis steps.
