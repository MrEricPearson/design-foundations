### Structural Flow (narrative sections marked by `---` breaks)

**Section 1: Goal + Prior Knowledge Hook**  
Opens with wrong-model hook (moderated = only way) → introduces unmoderated as the flip → scale/speed tradeoff made explicit

**Section 2: Trigger**  
When to use this method — prototype/feature/flow uncertainty, need answers before shipping

**Section 3: Concept**  
Mechanism: realistic conditions → unfiltered behavior → task as control → variance as signal  
Citations: Nielsen (1993) on model divergence

**Section 4: Method**  
7-step sequence:
1. Pick the thing (URL requirement)
2. Write three tasks (goal-not-path framing)
3. Write screener question (filters real users)
4. Set up in tool (Maze/UserTesting/Lookback)
5. Send the link (panel or direct)
6. Watch recordings (hesitation + abandonment patterns)
7. Document blockers (repeated vs edge-case)

Citations: Krug (2010) on task writing, Sauro & Lewis (2016) on screening, Nielsen (2000) on sample size

**Section 5: Artifact**  
Session recordings + blocker notes + completion patterns

**Section 6: Watchout**  
Failure mode: tasks that teach instead of test → instruction-creep diagnostic → rewrite as outcome

**Section 7: Try This**  
5-minute practice: write one task for current work, read aloud, detect instruction-creep

**Section 8: Proof (follows Try This)**  
Observable signal: task reads like coworker instruction, reveals hidden assumptions

**Section 9: Take This Further**  
Spaced practice: write 2 more tasks over 2 days → test with 1 real user → reflection prompt: "what surprised you about what they said they'd do first?"  
Includes shareout: Platform Excellence channel

**Section 10: AI Path**  
Post-attempt framing: upload session notes → AI groups by problem type → prioritized fix list

**Section 11: What Next**  
Conditional routing:
- No friction → scale test or move to 215c (task success rates)
- Repeated blockers → redesign + retest
- Scoping issues → revisit task difficulty (references 123)

**Section 12: Sources**  
APA format, full citations for all 4 sources
