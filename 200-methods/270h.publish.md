### Section Breakdown

| Section | Content Start | Visual Treatment | Purpose |
|---------|--------------|------------------|---------|
| **Goal** | "Test multiple directions simultaneously..." | Plain text, declarative | Orient reader to single outcome |
| **Prior Knowledge Hook** | "You already know prototyping answers questions..." | Standard prose | Validate existing schema before adding |
| **Trigger** | "Here's what normally happens. The team picks a direction..." | Pattern description, 2nd person present | Drop reader into recognizable situation |
| **Concept** | "Steven Dow ran an experiment at Stanford..." | Research narrative → mechanism | Causal explanation of why comparison > iteration |
| **Quotable Line** | "Testing one prototype asks: does this work? Testing multiple asks: which works better?" | Blue highlight panel or styled blockquote | Viral mechanic — forwardable insight |
| **Method** | "Step 1: Define the question..." through "Step 5: Extract the principle" | Numbered steps, imperative voice | Unambiguous execution path |
| **Artifact** | "When you're done, you have three things..." | Standard prose after Method | Tangible output definition |
| **Watchout** | "The failure mode that catches even experienced teams..." | Personal register, honest | Specific failure mode with mitigation |

| **Proof** | "When one prototype consistently outperforms..." | Calibration feedback, includes false-positive diagnostic | Mode B — "if you see X, it worked" |
| **Take This Further** | "Over the next three to five days..." | Invitation register, includes share prompt | Spaced practice with reflection |
| **AI Path** | "After you've run this yourself..." | Optional acceleration, post-attempt framing | Extends method, doesn't replace |
| **What Next** | "Once you've chosen the direction..." | Conditional routing | Links to 270b, 270f, 301, 215a |
| **Sources** | Four academic sources, APA inline | Standard reference block | Verifiable authority |

## Visual Design Notes

### Blue Highlight Panel (Quotable Line)
Placed after Concept section, before Trigger continuation:
> **Testing one prototype asks: does this work? Testing multiple asks: which works better? Only the second question generates transferrable principles.**

**Styling:** Background: `#EBF0FA` (light) / `#1A2840` (dark), border-left: 4px solid accent, padding: 1rem 1.25rem, font-style: normal (not italic), text remains regular weight.
