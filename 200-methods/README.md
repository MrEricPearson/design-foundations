# Tier 200 — Practical Methods

**40 methods.** Each has named steps, a concrete output, and a single watchout. Each takes under 5 minutes to read; under an hour to run.

Methods build on Tier 100 concepts. Prerequisites are listed in each piece's header. When in doubt, read the Tier 100 concept first — most are 3 minutes.
