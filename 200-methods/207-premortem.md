# Premortem
**Tier:** 200 — Practice | **Arc:** Standalone | **Note:** Pairs with 108 (Five Whys); candidate technique inside 304 (Workshop arc)

**Goal:** After this piece, you will be able to generate a specific list of failure modes before committing to a direction — so the list exists when it can still change something.

**Prior knowledge hook:** Think of a project that failed for a reason you could have seen coming if you'd looked. The failure mode was visible in hindsight — specific, not surprising — but nobody named it before the work started.

**Trigger:** you're about to commit to a direction and want to catch risks before they happen, not after.

**Why this works:** committing to a direction changes how you process risk — you start defending the direction rather than questioning it. Running the premortem before the commitment keeps the mind in questioning mode, which is the only mode that produces honest failure analysis.

**Method:** as a group (or solo), imagine it's finished and it failed. Ask what went wrong. List real, specific reasons, not vague ones.

**Artifact:** a short list of specific failure modes, gathered before you've actually failed any of them.

**Watchout:** this can turn into pure pessimism if not framed carefully — the goal is catching real risks, not talking each other out of trying.

**Try This:** for something you're currently about to commit to, write "It's 6 months from now, and this failed. The three most specific reasons are: ___." Write them down now, before you start.

**Proof:** If the list contains at least one item that nobody said aloud before the session — a risk someone knew but hadn't named — the method worked. A list where every item was already in the room confirms what was already known; it doesn't derisk. The measure: someone says "I hadn't thought of that" at least once. If that moment never arrives, the session was comfortable but not useful.

**Take this further:** in the next week, revisit the failure list you wrote. Cross off any that you've already addressed in the design. Circle any that still feel live. Write one sentence: what decision would you change if you took the most dangerous uncrossed item seriously?

**After you've run this yourself:** describe your current direction and context to an AI tool and ask it to roleplay as a skeptic listing specific, realistic failure modes — use the output as a starting list to react to and extend.

**What Next:** if a failure mode traces back to an unvalidated assumption, return to 101 (Not All Assumptions Are Equal) to rank and address it. If you want to run this with a group, read 304 (Running One Workshop) — premortem is a strong opening exercise.
